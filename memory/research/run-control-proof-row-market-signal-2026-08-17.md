## Buyer-Safe Wedge
Use "proof rows" as the shared control surface across property ops and governed agents:

`workflow | source record | requested action | represented owner/user | tool/system touched | policy/approval state | evidence link | exception path | counted outcome`

For property ops, the row should prove the rent/delinquency/renewal/maintenance action was reviewed and traceable before money, notices, access, or tenant-facing messages move.

For AI enablement, the same row should prove an agent or workflow acted under the right identity, policy, data boundary, and reviewer mode before the result is counted.
