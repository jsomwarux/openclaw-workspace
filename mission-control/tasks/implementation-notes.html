Atomic Create-Only Task Admission — 2026-09-11

Decision: Preserve normal keyed POST upsert behavior. Add an explicit mode=create-only path for immutable payload-version cards.

Design

  • The Convex mutation queries the indexed dedupeKey and, inside one mutation, either returns the existing ID untouched or inserts the new task once.
  • An existing task is never patched in create-only mode, so completed, in-progress, or archived human state cannot be reopened by an adapter race.
  • Missing dedupe keys and unknown modes fail with HTTP 400. Normal POST behavior is unchanged.
  • No schema migration, deployment, production data write, or schedule change is part of this branch.

Tradeoff

A separate explicit mode keeps backward compatibility for existing callers while providing the stronger write contract required by the jt-ops adapter.

Files

convex/tasks.ts, app/api/tasks/route.ts, two pure helpers and their tests, plus task and implementation records. Pull request: #1.
